# 计算机网络基础与性能指标（第1.1 - 1.6节）2026.11.12

## 一、 计算机网络基础概念（第1.1 - 1.4节）

### 1. 核心定义与发展
*   **发展阶段**：通讯基础设施 ➔ 信息服务基础设施。
*   **网络（Network）**：由若干**结点**和连接结点的**链路**组成。
*   **互连网（internet）**：由路由器连接多个网络而成，是“网络的网络”（通用名词）。
*   **因特网（Internet）**：世界上最大的互连网（专有名词）。**1983年**诞生，核心是 **TCP/IP 协议**。
*   **万维网（WWW）**：基于因特网提供的一种信息服务（常与因特网混淆，需注意区分）。

### 2. 因特网服务提供者（ISP）
*   即我们常说的三大运营商。
*   作用：面向公众提供网络接入服务。
*   前提：**必须有 IP 地址才能通信**。
*   相关组织：RFC 技术文档（免费下载）、因特网协会 ISOC。

### 3. 因特网的组成
*   **边缘部分**：由所有连接在因特网上的**主机**组成。是用户直接使用的部分，用于**通信和资源共享**。
*   **核心部分**：由大量网络和连接这些网络的**路由器**组成。为边缘部分提供服务。
    *   **路由器**：专用计算机，是分组交换的关键构件。
    *   **核心功能**：构造发送端 ➔ **存储转发** ➔ 接收还原。

### 4. 计算机网络的定义与分类
*   **定义**：互联、自治的集合。是通用、可编程的硬件互联，用来传送多种不同类型数据，支持广泛且日益增长的应用。
*   **分类**：
    *   按使用者：公用网、专用网。
    *   按传输介质：有线网、无线网。
    *   按覆盖范围：广域网（WAN）、城域网（MAN）、局域网（LAN）、个域网（PAN）。

## 二、 计算机网络的性能指标（1.5节）

### 1. 速率 (Rate)
*   **单位**：bit（比特）。`8 bit = 1 Byte`（字节）。
*   **容量换算**：`kB = 2^10 B`, `MB = 2^20 B`...
*   **⚠️ 易错计算**：带宽单位通常带 bit，文件大小通常带 Byte。
    *   *计算示例*：`100MB / 100Mbps = (2^20 B) / (10^6 b/s) = (2^20 * 8 b) / (10^6 b/s) ≈ 8.3s` （注意时间单位换算和 8 倍关系）。

### 2. 带宽 (Bandwidth)
*   **原本含义**：信号占据的频率范围（单位：Hz, kHz, MHz, GHz）。
*   **网络含义**：通信线路能运送的**最高数据率**。

### 3. 吞吐量 (Throughput)
*   **定义**：单位时间内通过某个网络（信道、接口）的数据量。
*   **限制**：受带宽或额定速率的限制。

### 4. 时延 (Delay)
*   **发送时延** = `分组长度(b) / 发送速率(b/s)`
*   还包括：传播时延、处理时延。

### 5. 其他关键指标
*   **时延带宽积**：`传播时延 × 带宽`，代表以比特为单位的链路长度。
*   **往返时间 (RTT)**：数据双向交互所需的时间。
*   **利用率**：
    *   信道利用率：某信道有百分之几的时间有数据通过。
    *   网络利用率：全网络信道利用率的加权平均。
    *   *注意：并非越高越好，通常不超过 50%，但也别太低。*
*   **丢包率**：`丢失的分组 / 总分组`。
    *   原因：误码被丢弃、队列已满被丢弃（拥塞情况：轻度 1-4，严重 5-15）。

## 三、 计算机网络体系结构（1.6节）

### 1. 分层模型
*   **TCP/IP 体系结构**（事实上的国际标准）：
    *   应用层：HTTP, SMTP, DNS, RTP
    *   运输层：TCP, UDP
    *   网际层：IP （路由器工作在这一层）
    *   网络接口层
*   **原理体系结构**（结合 OSI 的五层结构）：
    *   应用层、运输层、网络层、数据链路层、物理层。

### 2. 结构分层的必要性
*   网络是非常复杂的系统，分层易于研究处理。
*   物理层：接口、介质（如网线）。
*   网际层：IP 地址（前3位网络，第4位具体主机）。

### 3. 各层解决的核心问题（重要！）
*   **应用层**：解决通过应用进程的交互来实现特定网络应用的问题。
*   **运输层**：解决**进程之间**基于网络的通信问题。
*   **网络层**：解决分组在多个网络传输（**路由**）的问题。
*   **数据链路层**：解决分组在**一个网络（或一段链路）**上传输的问题。
*   **物理层**：解决用何种**信号**来传输比特的问题。

## 一、 分层思想举例：数据的封装与解封装(1.63)
以主机访问 Web 服务器为例，数据在发送端是自上而下逐层封装，在接收端是自下而上逐层解封装。

*   **应用层**：生成 HTTP 报文。
*   **运输层**：加上 TCP 首部（或 UDP），形成 TCP 报文段。
*   **网络层**：加上 IP 首部，形成 IP 数据报。**（路由器工作在这一层，只拆解到 IP 首部来找路）**
*   **数据链路层**：加上 ETH 首部（MAC地址等），形成帧。
*   **物理层**：转化为比特流（加上前导码）发送出去。

*注：从 Web 服务器返回主机时，箭头是相反的，即逐层解封装。OSI 七层模型则是：应用 -> 表示 -> 会话 -> 传输 -> 网络 -> 链路 -> 物理。*

## 二、 计算机网络体系结构专用术语

### 1. 实体与协议
*   **实体**：任何可以发送或接收信息的硬件或软件进程。
*   **对等实体**：相同层次中的实体。
*   **协议**：为进行网络中的数据交换而建立的规则、标准或约定。两个对等实体间的通信规则。
    *   **语法**：数据与控制信息的结构或格式（比如格子的长度、先后顺序）。
    *   **语义**：需要发出何种控制信息，完成何种动作以及做出何种响应（收发方要完成的操作）。
    *   **同步**：事件实现顺序的详细说明（收发双方的时序关系）。

### 2. 服务与透明性
*   **服务**：在协议控制下，两个对等实体进行逻辑通信，使本层能够向上一层提供服务。
*   **实现本层协议，需使用下面一层所提供的服务。**
*   **关键结论**：**协议是水平的，服务是垂直的。**
*   **透明性**：实体看得见下层提供的服务，但并不知道下层具体是怎么实现该协议的（即协议对上层是“透明”的）。
![1.63-1.64](images\webnote4.JPG)

### 3. 服务访问点 (SAP)
相邻两层实体交换信息的逻辑接口，用于区分不同的服务类型：
*   **运输层**：端口号。
*   **网络层**：IP 首部中的“协议字段”。
*   **数据链路层**：帧的“类型”字段。

### 4. 数据单元 (PDU & SDU)
*   **协议数据单元 (PDU)**：对等层次之间传递的数据包。各层叫法不同：
    *   应用层：报文 (Message)
    *   运输层：TCP 报文段 (Segment) 或 UDP 用户数据报 (Datagram)
    *   网络层：IP 数据报或分组 (Packet)
    *   数据链路层：帧 (Frame)
    *   物理层：比特流 (Bit stream)
*   **服务数据单元 (SDU)**：同一系统内，层与层之间交换的数据包。
    *   多个 SDU 可以合并为一个 PDU，一个 SDU 也可以分为多个 PDU。
*   **服务原语**：上层使用下层服务时，必须与下层交换的一些命令。

## 三、 章节核心习题结论
1.  在 OSI 参考模型中，自下而上第一个提供**端到端**（进程到进程）服务的层次是：**运输层**。（网络层只提供主机到主机的服务）
2.  不属于网络体系结构所描述的内容是：**协议的内部实现细节**。（只描述“做什么”，不管“怎么做”）
3.  TCP/IP 参考模型的网络层提供的服务是：**无连接不可靠的数据报服务**。
4.  IP 协议直接为：**ICMP 协议**提供服务。
5.  OSI 中负责数据格式转化的是：**表示层**。
