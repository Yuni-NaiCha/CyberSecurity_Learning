# 25-HTTP 状态码对照表

## 一、先看开头数字

| 开头 | 含义 | 说明 |
|---|---|---|
| 2xx | 成功 | 请求被正常处理 |
| 3xx | 跳转 / 缓存 | 资源在别处，或用缓存 |
| 4xx | 客户端问题 | 认证、权限、地址、参数 |
| 5xx | 服务器问题 | 服务端自己出错 |

## 二、七个必会 + 一个常考

| 状态码 | 一句话 | 工作里的典型场景 |
|---|---|---|
| 200 OK | 请求成功 | 正常浏览页面、接口返回 JSON |
| 301 Moved Permanently | 永久跳转 | 换域名、http 升级 https |
| 302 Found | 临时跳转 | 维护公告页、活动页临时跳转 |
| 304 Not Modified | 内容没改，用缓存 | 浏览器带缓存请求，服务器确认未变 |
| 401 Unauthorized | 没认证 / 认证失败 | 未登录、密码错误、会话过期 |
| 403 Forbidden | 有身份但没权限 | 普通用户访问管理员接口 |
| 404 Not Found | 资源不存在 | 页面被删、接口下线、路径写错 |
| 500 Internal Server Error | 服务器内部错误 | 代码异常、数据库连不上、磁盘写满 |

## 三、三对最容易混的

**401 与 403**

```
401：你是谁？先认证（没登录、密码错）
403：知道你是谁，但你不许（权限不足）
```

**301 与 302**

```
301：永久搬家，以后都去新地址（浏览器和搜索引擎会记住）
302：临时出门，下次还请求旧地址
```

**304 与 404**

```
304：东西还在，只是没改，用缓存
404：东西根本不存在
```

## 四、工作里怎么用

- **看监控**：4xx 比例突然升高 → 客户端在出错（登录失败、扫目录）；5xx 升高 → 服务端出问题。
- **排障**：401 先查认证（Cookie / Token）；403 查权限配置；404 查路径与路由；500 查服务日志。
- **安全**：同一 IP 短时间大量 401 是密码爆破特征；大量 404 可能是目录扫描；403 集中出现可能是越权尝试。

## 五、总结

1. 先看开头数字定大类，再看具体码定原因。
2. 401 是“没认证”，403 是“没权限”，两者不要混。
3. 301 永久、302 临时；304 不是错误，是“用缓存”。
4. 4xx 多数是请求方的问题，5xx 是服务端的问题。
5. 安全场景里，401 的频次、404 的密度、5xx 的突增都是信号。

---

## 六、学习作用

- 看到任何 HTTP 响应，能立刻判断是成功、跳转、请求方问题还是服务端问题。
- 排查线上问题时，能按状态码缩小范围：认证、权限、路径、服务端。
- 看访问日志时，能从状态码分布发现爆破（401）、扫描（404）、服务异常（5xx）。
