# 00-环境下载进度

## 目标

把虚拟机（VirtualBox）、Linux系统（Ubuntu 22.04）和代码编辑器（VS Code）全部配齐。

## Linux系统（Ubuntu 22.04）遇到了什么坑 & 怎么解决的

1. **清华源下载很慢**
   - **情况**：一开始用浏览器自带下载器下Ubuntu镜像，速度只有 133KB/s，预计要下 9 个小时，直接崩溃。
   - **解决**：搜了下发现用多线程下载器能破。换了开源的 FluxDown，速度瞬间飙到 18.7MB/s，几分钟就搞定了。
2. **阿里云镜像是个坏的**
   - **情况**：中途想换阿里云，结果发现它的 `iso` 文件大小只有 41B（明显不对）。
   - **解决**：果断放弃，换回清华源。
3. **VS Code 官网打不开**
   - **情况**：域名解析失败（ERR_NAME_NOT_RESOLVED），连手机5G都打不开微软的 CDN 节点。
   - **解决**：最后在浏览器里反复刷新，直接在主站点的下载链接里下下来了（顺便避开了那些乱七八糟的第三方下载站）。

## Git 安装与初始化配置（踩坑日记）

### 一、为什么要装 Git？

Git 可以帮我在本地记录每一次修改，以后还能把笔记一键推送到 GitHub 上，打造成我找工作的专属作品集。

### 二、安装过程中的“生死抉择”

下载安装包后，一路 Next，但有三个地方差点踩坑：

1. **默认编辑器（Choosing the default editor）**
   - **坑**：默认是 `Vim`，听说是个进去了就退不出来的“魔鬼编辑器”。
   - **解决**：下拉菜单选了 `Use Visual Studio Code as Git's default editor`。这样以后写提交说明，会自动弹出熟悉的 VS Code 界面。

2. **初始分支名（Initial branch name）**
   - **坑**：默认分支叫 `master`，但这是老黄历了。
   - **解决**：选择了 `Override...`，把名字改成了 `main`，跟目前主流的 GitHub 保持同步。

3. **环境变量（PATH environment）**
   - **解决**：选了中间的 `Git from the command line and also from 3rd-party software`。只有选这个，以后在 CMD 或 VS Code 里才能直接召唤 Git。

### 三、配置身份（为了隐私，特意注册了新邮箱）

安装完第一步，必须让 Git 知道我是谁。
因为搞网安的对隐私特别敏感，绝对不能用包含真实姓名的私人主邮箱，所以特意去注册了一个专属 Gmail。

**避坑记录**：
1. **名字千万别用中文**：一开始想用中文昵称，被告知中文在某些系统里会显示成乱码。最后改成了拼音 `Yuni_NaiCha`。
2. **命令少敲了空格**：输入邮箱时，`user.email` 和双引号之间必须有一个空格。一开始没敲空格，导致命令失败，补上空格才通过。

```bash
# 最终成功的配置命令
git config --global user.name "Yuni_NaiCha"
git config --global user.email "yuninaicha6@gmail.com"
```
