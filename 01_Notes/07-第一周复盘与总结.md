# 07-第一周复盘与总结（00—09）

## 一、 本周学习流程回顾

1. **基建狂魔**：下载 Ubuntu 镜像，安装 VirtualBox 虚拟机，配置 VS Code 与 Git 环境。
2. **网络底子**：掌握体系结构、TCP/IP 四层模型、PDU 与性能指标。
3. **终端实操**：在 Ubuntu 中实操 8 个核心网络排查命令（ip, ping, nslookup, curl 等）。
4. **网络进阶**：将虚拟机从 NAT 改为桥接模式，突破 Windows 防火墙拦截，实现双向 Ping 通。
5. **合规底线**：学习网安法核心制度，明确等保要求与从业者绝对红线。
6. **地址与链路**：IP 跨网、MAC 同链路，ARP 把 IP 换成 MAC；集线器广播、交换机按 MAC 表转发（03、08、09）。
7. **作品集沉淀**：建立包含目录体系的 GitHub 仓库，掌握 Markdown 图文混排。

## 二、 重点注意事项（踩坑经验）

*   **环境配置**：Ubuntu 安装切忌选“无人值守”；Linux 用户名绝对不能用 `root`；终端输入密码屏幕不显示（盲打即可）。
*   **网络互通**：桥接模式下，虚拟机 ping 不通物理机，90% 是 Windows Defender 防火墙拦截了 ICMP 入站请求，测试完务必重新开启防火墙。
*   **代码规范**：Linux 命令严格区分大小写，且极其注重空格；Markdown 代码块必须用 ` ``` ` 闭合，图片路径严禁带中文和空格。
*   **隐私保护**：技术笔记发到公网前，必须对本地真实 IP、MAC 地址及电脑用户名进行脱敏处理。

## 三、 学习内容提炼

*   **理论**：理解了网络分层设计哲学（应用层、运输层、网际层、网络接口层）及数据封装逻辑。
*   **实操**：掌握了域名解析（DNS）、连通性测试（ICMP）、路由追踪（Trace）以及 HTTP 报文抓取（curl）的基础原理。
*   **合规**：牢记“日志留存不少于 180 天”，死守“只打本地靶场，未经授权扫描即违法”的法律红线。

## 四、 难点与不足（下周怎么补）

*   **痛点**：Linux 命令的拼写和参数容易手滑（如 `curl` 拼成 `crul`，漏打空格）。
*   **改进**：不追求死记硬背，熟练使用 `↑` 键调出历史命令，并结合笔记进行复制粘贴，增加实际敲击频率。对于底层原理（如 TTL 机制、子网掩码计算），在后续实操中逐步加深理解。
